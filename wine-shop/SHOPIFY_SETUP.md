# SHOPIFY_SETUP.md — Shopify管理画面セットアップ手順

このドキュメントは、`wine-shop/`のテーマコードを実際に動かすために**Shopify管理画面側で行う設定**をまとめたものです。テーマの実装（コード）が進むフェーズ3以降に合わせて、該当箇所から順に実施してください。

> ⚠️ 法定表示（特商法表記・年齢確認・酒類販売管理者標識など）に関する内容は、本ドキュメントおよびテーマ内のテキストはすべて**仮の文言**です。正式公開前に必ず税務署・行政書士・弁護士などの専門家確認を受けてください。

---

## 1. Shopifyストア作成・開発ストア設定

1. [shopify.com](https://www.shopify.com/) でアカウントを作成、または既存パートナーアカウントで開発ストアを作成
2. Shopifyプラン：開発中は無料の開発ストア（Development store）で進め、公開直前に有料プランへ切り替え
3. ストアの基本情報（店舗名、住所、業種＝酒類販売）を入力
4. 管理画面 → 設定 → 一般 で店舗の法的名称・所在地・連絡先を正式なものに更新

---

## 2. Shopify CLIセットアップ（開発者向け）

```bash
# Shopify CLIのインストール（Node.js 18+ 前提）
npm install -g @shopify/cli @shopify/theme

# Shopifyへログイン
shopify auth login

# 開発ストアに接続してテーマ開発を開始
cd wine-shop
shopify theme dev --store={your-store}.myshopify.com

# ローカルの変更を確認用テーマとしてpush（本番公開はしない）
shopify theme push --unpublished

# 完成後、本番テーマとして公開
shopify theme push --live
```

詳細な開発フローはREADME.md（後続フェーズで作成）に記載します。

---

## 3. 商品登録

1. 管理画面 → 商品 → 商品を追加
2. DATA_MODEL.md「6. 商品登録例」の項目に沿って入力
3. Tagsは半角カンマ区切りで`type:red`のようなプレフィックス付きタグを付与（DATA_MODEL.md 2節）
4. メタフィールドはこのSHOPIFY_SETUP.md「5. メタフィールド作成」を先に完了させてから入力可能になります
5. 開発確認用に、最低5〜10点程度、ワインタイプ・国・価格帯が異なる商品を登録し、フィルター・並び替えの動作確認に使えるようにしてください

### 開発用CSV雛形

商品を一括登録する場合は、管理画面 → 商品 → インポートからCSVを取り込めます。以下は最小限の列構成の例です（Shopify標準CSVフォーマットに準拠、実際のインポート時は管理画面からエクスポートしたテンプレートに列を合わせてください）。

```csv
Handle,Title,Body (HTML),Vendor,Type,Tags,Published,Variant Price,Variant Compare At Price,Image Src
chateau-sample-2018,シャトー・サンプル 2018,"<p>凝縮感のある果実味と滑らかなタンニン。</p>",Château Sample,赤ワイン,"type:red,country:france,pairing:beef,occasion:anniversary",TRUE,6800,7500,https://example.com/images/sample-red.jpg
domaine-sample-blanc-2021,ドメーヌ・サンプル 白 2021,"<p>爽やかな柑橘とミネラル感。</p>",Domaine Sample,白ワイン,"type:white,country:france,pairing:sushi",TRUE,4200,,https://example.com/images/sample-white.jpg
```

CSV取り込み後、メタフィールド値は管理画面から個別に補完するか、メタフィールド対応のCSV列（Shopifyがエクスポート時に生成する列名）を使って一括更新してください。

## 4. コレクション登録

DATA_MODEL.md「5. コレクション設計」に従い、管理画面 → 商品 → コレクション から作成します。

### 自動コレクションの作成手順（例：「赤ワイン」）

1. コレクションを作成 → コレクションの種類で「自動」を選択
2. 条件：「商品タグ」が「完全に一致する」「type:red」
3. 並び替え：おすすめ順（または新着順）
4. SEOタイトル・説明を入力

同様の手順で国別・地域別・価格帯別・セール・料理別・シーン別コレクションを作成してください（各条件はDATA_MODEL.md参照）。

### 手動コレクションの作成手順（例：「ソムリエのおすすめ」）

1. コレクションを作成 → コレクションの種類で「手動」を選択
2. 商品を個別に検索して追加
3. 並び順はドラッグ&ドロップで調整可能

---

## 5. メタフィールド作成

管理画面 → 設定 → メタフィールド → 商品 で、DATA_MODEL.md 3節の全項目を作成します。

1. 「定義を追加」をクリック
2. 名前（表示名）・namespace and key（`custom.xxx`の形式でxxx部分を入力）・説明・データ型 を、DATA_MODEL.mdの表と**完全に一致させて**登録（テーマのLiquidコードがこのkey名を直接参照するため）
3. `producer`・`pairing_foods`は「メタオブジェクトへの参照」型を選択し、先に6節のmetaobject定義を作成してから設定
4. `wine_type`・`farming_method`など固定値運用のフィールドは、可能であれば「検証」設定で選択肢リストを設定し入力ゆれを防止
5. 各フィールドの「ストアフロントで公開」をONにする（フィルター対象にするため）
6. フィルター対象にする項目（DATA_MODEL.mdで「フィルター：○」の項目）は、この時点でメモしておき、7節のSearch & Discovery設定で有効化する

---

## 6. Metaobject作成

管理画面 → 設定 → メタオブジェクト（またはコンテンツ → メタオブジェクト）から、DATA_MODEL.md 4節の3種類を定義します。

### Producer（生産者）

1. 「定義を追加」→ 名前「Producer」、type handle `producer`
2. フィールドをDATA_MODEL.md 4-1の表通りに追加
3. 「エントリーごとのテーマテンプレートを有効化」をONにし、`templates/metaobject/producer.json`が使われるようにする
4. 保存後、「エントリーを追加」で実際の生産者データを登録

### Feature（特集）

1. 名前「Feature」、type handle `feature`
2. フィールドを4-2の表通りに追加
3. 必要に応じてテーマテンプレートを有効化

### Food pairing（料理ペアリング）

1. 名前「Food pairing」、type handle `food_pairing`
2. フィールドを4-3の表通りに追加

## 7. Search & Discovery設定

1. 管理画面 → アプリ → 「Search & Discovery」（Shopify公式アプリ、未インストールの場合はShopifyアプリストアから追加）
2. 「フィルター」タブで、コレクションページに表示するフィルターを選択
3. DATA_MODEL.mdで「フィルター：○」となっている項目（ワインタイプ、価格、国、地域、品種、生産者、ヴィンテージ、味わい4種、料理、シーン、栽培方法、容量、在庫あり、ギフト対応、セール）を追加
4. 各フィルターの表示形式（チェックボックス／レンジ／星評価など）を選択。rating型の項目（ボディ・甘辛度・酸味・渋み）は星または数値レンジ表示を選択
5. 「予測検索」タブで、検索対象フィールド（商品名、Vendor、商品タイプ、タグ、説明、対応するメタフィールド）を有効化
6. 検索結果の同義語設定（例：「泡」→「スパークリング」）を必要に応じて追加

---

## 8. Navigation設定

1. 管理画面 → オンラインストア → ナビゲーション
2. 「メインメニュー」を編集し、SITE_STRUCTURE.md 2節のグローバルナビゲーション構造に沿ってリンクを作成
   - 「ワインを探す」はドロップダウン：赤／白／ロゼ／オレンジ／スパークリング／甘口／酒精強化 の各コレクションへリンク
   - 「料理から探す」「シーンから探す」も同様にコレクション/Food pairingページへのサブメニューを作成
3. 「フッターメニュー」を編集し、法定表示ページ群（特商法表記、返品・キャンセル、利用規約、プライバシーポリシー、年齢制限表示、酒類販売管理者標識、お問い合わせ、配送・送料、FAQ）へのリンクを追加

---

## 9. 配送設定

1. 管理画面 → 設定 → 配送と配達
2. 配送エリア（国内／必要に応じて海外）を設定
3. 酒類は重量・割れ物のため、配送業者の梱包規定に合わせた配送料テーブルを設定
4. 一定金額以上で送料無料などのルールがあれば設定し、告知バー（announcement-bar）の文言と一致させる
5. 成人確認が必要な配送方法（宅配便の対面受け取りなど）を利用する場合、配送業者側のオプション設定を確認

---

## 10. 決済設定

1. 管理画面 → 設定 → 決済
2. Shopify Payments（対応国の場合）または利用する決済代行会社を設定
3. 利用可能な決済手段（クレジットカード、代表的な国内即時決済等）を有効化
4. 独自決済の実装は行わないため、この設定のみでチェックアウトが機能する

---

## 11. 税設定

1. 管理画面 → 設定 → 税金と関税
2. 日本国内販売の場合、消費税込み表示（税込価格表示）を有効化
3. 商品価格が税込表示になるようテーマ側の価格表示（`snippets/price.liquid`）とも整合を取る

---

## 12. ドメイン設定

1. 管理画面 → 設定 → ドメイン
2. 独自ドメインを接続する場合はここで追加・DNS設定を行う
3. 開発中は `{store}.myshopify.com` のままで問題ない

---

## 13. 法定ページ設定

1. 管理画面 → オンラインストア → ページ で以下を作成（テンプレートは`page.legal.json`を割り当て）
   - 特定商取引法に基づく表記
   - 返品・キャンセルについて
   - 利用規約
   - プライバシーポリシー
   - 20歳未満の飲酒・販売はできません（年齢制限表示）
   - 酒類販売管理者標識
2. 管理画面 → 設定 → ポリシー にも利用規約・プライバシーポリシーの正式版を登録すると、Shopify標準のチェックアウトフッターにも自動反映される
3. 前述の通り、全ての文言は仮テキストです。公開前に専門家確認を必ず行ってください

---

## 14. Blog（特集記事）設定

1. 管理画面 → オンラインストア → ブログ記事 で「Features」という名前のブログを作成
2. テンプレートに`blog.json`・`article.json`を割り当て
3. 季節特集はここに記事として作成（DATA_MODEL.md 4-2節の運用メモ参照）
