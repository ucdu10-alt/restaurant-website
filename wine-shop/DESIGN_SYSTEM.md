# DESIGN_SYSTEM.md — 匠 Wine Shop デザインシステム

株式会社匠 オンラインワインショップ（Shopifyテーマ）のデザイン原則とトークン定義。
実装（Liquid/CSS/JS）は必ずこの文書のトークン・ルールを参照し、値のハードコードを避けること。

---

## 1. コンセプト

**「ワインを探す時間そのものが心地よい」ワインセレクトショップ。**

量販型ECの「安売り感・情報過多・派手な演出」を避け、以下3点を常に満たす。

- **探しやすい** — 初心者は迷わず、詳しい人は細かく絞り込める
- **読みやすい** — 情報密度が高くても整理されていて疲れない
- **美しい** — 高級感は装飾ではなく、写真・余白・文字組み・情報整理で表現する

### 参考比率と採用要素

| サイト | 比率 | 採用する要素 |
|---|---|---|
| Berry Bros. & Rudd | 40% | 上質な余白／品格のあるタイポグラフィ／落ち着いた高級感／編集的レイアウト／白・生成り・淡いグレーの静かな画面構成 |
| Wine.com | 30% | 検索性／フィルター／ソート／商品一覧の視認性／分かりやすい購入導線／商品数が増えても迷わない情報設計 |
| La Cabane | 20% | 写真を主役にした構成／ミニマルなUI／情報を絞った商品カード／余白のある商品一覧 |
| IMADEYA ONLINE | 10% | 日本的な上質さ／セレクトショップとしての世界観／ブランドへの信頼感 |

**外見の模倣ではなく設計思想の参考**である点に注意。匠 Wine Shopは独自の配色・タイポグラフィで統一する。

### 明確に採用しない表現

過剰なアニメーション／長い画面遷移／スクロールジャック／パララックス／操作を妨げる演出／重い背景動画／安易な黒背景／金色の多用／強いグラデーション／過度な角丸・カードUI／強い影。

## 2. カラー

CSSカスタムプロパティとして `assets/base.css`（もしくは `snippets/css-variables.liquid`）内の `:root` に定義する。テーマエディターの「カラー設定」からブランドカラー・補助色のみ上書き可能にする（詳細はSHOPIFY_SETUP.md参照）。

```css
:root{
  /* Base */
  --color-bg:            #F7F5F0; /* ページ背景（生成り） */
  --color-bg-white:      #FFFFFF; /* カード・パネル背景 */
  --color-bg-subtle:     #EEEAE3; /* 淡い背景（タグ、テーブルの縞など） */

  /* Text */
  --color-text:          #1C1B19; /* メインテキスト */
  --color-text-subtle:   #6B6862; /* サブテキスト、キャプション */

  /* Brand */
  --color-brand:         #4B1F2A; /* ワインレッド。アクセントのみ、地の色として多用しない */
  --color-accent:        #8B7864; /* 補助色（アイコン、罫線装飾など） */

  /* Structure */
  --color-border:        #D9D5CE;

  /* Status */
  --color-error:         #9E2A2B;
  --color-success:       #3F6B50;

  /* Derived (計算・派生値。追加ハードコード禁止) */
  --color-brand-10:      rgb(75 31 42 / 10%);   /* ホバー背景等 */
  --color-brand-on:      #FFFFFF;               /* ブランドカラー上のテキスト */
  --color-focus-ring:    #1C1B19;
}
```

### 使用ルール

- `--color-brand`（ワインレッド）は **CTAボタン・価格の強調・選択状態・アクセントアイコンなど「ここぞ」という箇所のみ**。背景全面や大きな面積には使わない。
- ページ背景は基本 `--color-bg`。カード・フォーム・モーダルなど「浮かせたい」要素は `--color-bg-white`。
- 黒背景・金ベタ塗り・グラデーション背景は禁止。
- コントラスト比はWCAG AA（本文4.5:1以上、大きな文字3:1以上）を満たすこと。上記の組み合わせ（`--color-text` on `--color-bg` / `--color-bg-white`）はいずれもAA適合。

## 3. タイポグラフィ

フォントは最大2種類。

```css
:root{
  --font-body: "Noto Sans JP", -apple-system, BlinkMacSystemFont, "Hiragino Sans", sans-serif;
  --font-heading: "Cormorant Garamond", "Noto Serif JP", serif; /* 英字見出し中心。和文見出しはfont-bodyを太字で代用可 */

  --fs-base: 1rem;      /* 16px */
  --fs-sm:   0.875rem;  /* 14px。補足情報のみ */
  --fs-md:   1.125rem;  /* 18px */
  --fs-lg:   1.5rem;    /* 24px */
  --fs-xl:   2rem;      /* 32px */
  --fs-2xl:  2.75rem;   /* 44px */

  --lh-body: 1.7;
  --lh-heading: 1.3;

  --fw-regular: 400;
  --fw-medium: 500;
  --fw-bold: 700;
}
```

### ルール

- 本文は **16px以上**、行間 **1.6〜1.8**。
- 価格・容量・ヴィンテージ・アルコール度数などの**数字は等幅寄りの表示を優先**し、桁がガタつかないようにする（`font-variant-numeric: tabular-nums;` を数値表示snippet（`snippets/price.liquid`等）に適用）。
- 英字見出し用フォント（Cormorant Garamond等）は**見出しのみ**に限定し、本文・UIラベル・ボタン文言には使わない（可読性とパフォーマンスのため）。
- Webフォントは2ウェイト程度に絞り、`font-display: swap` を必須にする。日本語フォントはNoto Sans JPのサブセット化を検討（SHOPIFY_SETUP.md参照）。
- 見出し階層はh1→h2→h3を飛ばさない。1ページに`h1`は1つ。

## 4. スペーシング

8px単位のスペーシングスケール。

```css
:root{
  --space-1: 4px;
  --space-2: 8px;
  --space-3: 12px;
  --space-4: 16px;
  --space-5: 24px;
  --space-6: 32px;
  --space-7: 48px;
  --space-8: 64px;
  --space-9: 96px;
  --space-10: 128px;
}
```

marginやpaddingの値は必ずこのスケールから選ぶ。中間値（例: 20px）が必要に感じた場合は、隣接する2つの値のどちらかで代用しレイアウトを見直す。

## 5. グリッド・コンテナ幅

```css
:root{
  --container-max: 1280px;
  --container-prose-max: 820px; /* 760〜880pxの中間値。About/FAQ等の文章コンテンツ */
  --container-pad: var(--space-4); /* モバイル基準の左右余白 */
}
```

- 通常セクションは `max-width: var(--container-max); margin-inline: auto;`
- 文章中心ページ（About、FAQ、配送案内、法定表示等）は `--container-prose-max` に制限し、可読行長を確保する。
- 商品グリッドはCSS Gridを使用し、`grid-template-columns` はテーマエディターの「カード列数」設定（PC 3〜4列、タブレット2列、モバイル2列を既定値）に連動させる。

---

## 6. ボタン

```css
:root{
  --radius-sm: 2px;
  --radius-md: 4px;
  --radius-modal: 8px; /* モーダル・ドロワーのみ許容する上限 */
}
```

- 基本角丸は **0〜4px**。モーダル・ドロワーのみ最大8px。
- プライマリボタン：背景`--color-brand`、文字`--color-brand-on`、角丸`--radius-sm`、影なし。
- セカンダリボタン：背景透明、枠線`1px solid var(--color-text)`、ホバーで背景`--color-bg-subtle`。
- ボタン内の余白は`--space-3`（縦）×`--space-5`（横）を基準。
- タップ領域は最小 **44×44px** を確保（アイコンのみボタンも同様）。
- ホバー・フォーカス時のトランジションは150〜200ms、`ease`系のイージングのみ。

---

## 7. フォーム

- 入力欄・セレクト・テキストエリアは角丸`--radius-sm`、枠線`1px solid var(--color-border)`、フォーカス時は`--color-text`の2pxアウトライン（`:focus-visible`）。
- ラベルは常時表示（placeholderのみに依存しない）。
- エラー表示は`--color-error`＋テキストによる明示（色のみに依存しない。アイコン併記）。
- 必須項目は視覚的マーク＋`aria-required="true"`。

---

## 8. 商品カード

- 画像比率は**統一**（推奨 4:5、ボトル商品に適した縦長比率。`aspect-ratio`で固定し`object-fit: cover`）。
- 2枚目画像がある場合、ホバー（タッチ環境ではタップ不要・スワイプ非対応でよい）でクロスフェード切り替え（150ms）。
- 表示要素は商品画像／商品名／生産者／ヴィンテージ／国・地域／ワインタイプ／価格（通常・セール）／在庫状態／バッジ／お気に入りボタン／カート追加ボタンのみ。**長い商品説明文は表示しない**。
- 商品名は**2行までに`-webkit-line-clamp`で制限**し、名前の長さでカード高さが変動しないようにする。
- 影は原則付けない。境界は`1px solid var(--color-border)`または余白のみで表現。
- 角丸は`--radius-sm`のみ。

---

## 9. モーダル・ドロワー

- 角丸は`--radius-modal`（最大8px）まで。
- 背景オーバーレイは`rgba(28,27,25,0.4)`程度。
- 開閉トランジションは150〜200msのフェード＋わずかなスライド。
- フォーカストラップ必須、`Esc`キーで閉じる、開いている間は背景のスクロール・操作を防止（`inert`または`aria-hidden`＋`tabindex`制御）。
- カートドロワー、フィルタードロワー、モバイルナビドロワーで共通のスニペット/Web Componentを使う（`snippets`のモーダル共通化）。

---

## 10. フィルターUI

- PC：左サイドバー（sticky、ヘッダー分のオフセットを確保）。項目数が多い属性（品種・生産者・国など）は**アコーディオン**にして初期は主要フィルターのみ展開。
- モバイル：「絞り込み」ボタン→フルスクリーン/ボトムドロワー。適用ボタンには対象件数を表示（例：「24件の商品を見る」）。
- 選択中の条件は**チップ表示**（個別×で解除可能）＋「すべて解除」リンク。
- チェックボックス・レンジスライダー（価格）はキーボード操作・スクリーンリーダー対応必須。

---

## 11. アニメーション

### 許可

- ホバー：150〜200ms
- 控えめなフェード（要素の出現・消失）
- アコーディオンの開閉
- ドロワーの開閉
- カート追加時の短いフィードバック（例：カートアイコンの軽いバウンスやカウント更新、300ms以内）
- 商品画像のホバー切り替え

### 禁止

スクロールジャック／パララックス／自動再生背景動画／長いローディング演出／カーソル追従／目的のないフェードイン／大きなズーム演出／ページ遷移を遅らせる演出。

### 実装ルール

```css
@media (prefers-reduced-motion: reduce){
  *, *::before, *::after{
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
    scroll-behavior: auto !important;
  }
}
```

全てのtransition/animationはこのメディアクエリでの無効化対象に含める。

## 12. レスポンシブ

```css
/* モバイルファースト。min-widthで拡張していく */
--bp-lg-mobile: 480px;
--bp-tablet:    768px;
--bp-sm-pc:     1024px;
--bp-desktop:   1280px;
--bp-wide:      1440px;
```

- 基準は320px幅から崩れないこと。
- 商品グリッド列数：モバイル2列／タブレット2〜3列／小型PC以上3〜4列（テーマエディターで変更可能）。
- 確認必須環境：iPhone相当／Android相当／タブレット／小型ノートPC／大型デスクトップ。

## 13. 禁止表現まとめ（早見表）

| カテゴリ | 禁止 |
|---|---|
| 色 | 黒背景の多用、金色の多用、強いグラデーション |
| 形状 | 過度な角丸、強いカードシャドウ |
| 演出 | スクロールジャック、パララックス、自動再生背景動画、カーソル追従、目的のないフェードイン、大きなズーム |
| コピー | 「激安」「大特価」等の安売り表現、過剰な煽り文句 |
| UI | 訪問毎の大型年齢確認モーダル、操作を妨げるポップアップ |
